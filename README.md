# MP3かんたんプレイヤー

全盲の利用者がVoiceOverで使うことを想定した、端末内保存型の音楽プレイヤーです。画面モックから、実際のMP3の取り込み・保存・再生ができる実装へ移行しました。iPhone実機による受け入れ評価は別途必要です。

[プレイヤーを開く](https://taiki-1113.github.io/mp3-easy-player/)

## 使い方

1. iPhoneのSafariで開き、共有から「ホーム画面に追加」します。初回は通信が必要です。
2. 「初めて使うとき・保存について」の中で「オフライン利用の準備ができました」を確認します。
3. microSDを接続し、「音楽を取り込む」→「取り込み元のフォルダを選ぶ」で指定フォルダを選びます。
4. 保存中は画面を開いたままにし、完了後に新規・取り込み済み・失敗・未処理の件数を確認します。
5. 「音楽を聴く」からフォルダまたは全曲表示で曲を選びます。カードを外しても保存済みの曲を再生できます。

フォルダ選択にはiOS 18.4以降のSafariが必要です。選べない場合は補助操作の「MP3をまとめて選ぶ」を利用できます。毎回同じ取り込み元フォルダを選んでください。フォルダを別の階層から選ぶと、同じ内容の曲でも別のフォルダ所属として表示される場合があります。

## 機能

- サブフォルダを含むMP3一括取り込み。ファイル名優先、自然順。
- 増分SHA-256による内容一致判定。実体は1つ、複数フォルダへの所属はそれぞれ保持。
- IndexedDBに曲本体とフォルダ所属を1曲単位のトランザクションで保存。中止しても保存済みの曲は保持。
- 実音声の再生・一時停止・次／前・連続再生・末尾から先頭への繰り返し。
- 初期表示はすべての曲。画面先頭の「すべての曲」「フォルダ別」ボタンで切替。全曲表示では曲を選ばず再生ボタンから開始可能。順番／シャッフルを選択。現在曲を保ち、1周内は同じ実体を重複させない。
- ロック画面の曲情報と操作をMedia Sessionで提供。対応状況は端末・ブラウザに依存。
- 1曲／フォルダの削除。フォルダ削除は子階層を含み、他フォルダに所属する曲は保持。原本は削除しない。
- 破損した形式の取り込み失敗を表示。再生時エラーは次曲へ進み、全曲失敗なら停止。
- Service Workerによるオフライン資材保持。端末内の音声へのRange要求を処理。
- 高コントラストの明色／暗色、標準ボタン・選択欄・確認画面、短い読み上げ通知とフォーカス管理。現在曲と状態はまとめて読み上げ、時間と再生範囲は「再生の詳細」から確認。

## 保存と通信

音楽は選択した端末のブラウザ内に保存し、GitHubや外部サーバーへアップロードしません。GitHub Pagesにはアプリ資材だけを配置します。

初回準備・更新には通信が必要です。曲の保存先はキャッシュと別のIndexedDBです。保存の永続化も要求しますが、ブラウザのデータ削除・アプリ削除・空き容量などによる消失を完全には防げません。WindowsとmicroSDに原本を残してください。別ブラウザや別の配信URLとは保存領域を共有しません。

## 検証状況と制約

自動テスト29件が成功しています。公開URLで合成MP3の実ファイル2曲を保存し、別フォルダへの共有所属、破損の報告、再読み込み後の保持、実音声の進行、曲末の自動切替と繰り返し、重複の再保存防止を確認しました。削除の実DB／画面統合と実際の機内モードは未検証です。ローカルサーバーは起動しません。

**iPhoneのmicroSDアダプタ、VoiceOver、ロック中の曲末移行、機内モード、着信とイヤホン切断は、対象実機での確認が必要です。** ブラウザが背景で停止した場合に、Webアプリ側から無制限の実行を強制できるものではありません。

MP3の先頭フレームを検査しますが、音声全区間の破損やあらゆるMP3亜種の事前検出を保証しません。容量不足や途中の読み取り不能は中断結果として案内します。

```sh
node --test tests/*.test.js
node --check docs/app.js
```

公開元はmainブランチの/docsです。フレームワーク・外部CDN・有料音楽サービスを必要としません。
