# MP3かんたんプレイヤー：画面モック

全盲の利用者がVoiceOverで使うことを想定した、MP3プレイヤーの画面・操作の見本です。HTML・CSS・JavaScriptだけで動作します。

**音楽は流れません。実ファイルの取り込み・保存・削除は行いません。** サンプル一覧だけをメモリ上で変更し、再読み込みで初期状態へ戻ります。

## 操作

- ホームの「音楽を聴く」「音楽を取り込む」の2つから開始。
- フォルダ別／全曲の切替、ファイル名による曲選択。
- 再生／一時停止、次・前の操作見本。先頭と末尾を循環。
- 全曲表示では順番再生／シャッフル再生を選択可能。フォルダ別はファイル名順。
- シャッフルは選択曲から開始し、残りをランダムに並べ、1周内は重複なし。同じ順序で繰り返し、曲の選び直しや再生方法の変更で再構成。
- サンプルの一括取り込み、重複除外、中止・結果表示。
- 曲・フォルダ削除の確認。共有曲は別の所属に残す。

標準のボタン・選択欄・ダイアログ、ラベル、結果通知、フォーカス復帰を用いています。iPhone実機のVoiceOver適合や、ロック中の連続再生は未検証です。

## 公開

GitHub Pagesの公開元は `main` ブランチの `/docs` です。公開ファイルには音楽・個人データ・認証情報を含みません。公開ページの閲覧にChatGPTのログインは不要です。

画面構成を保ち、弱視・色の見分けにくさを考慮した高コントラスト配色を使用します。通常は明るい灰色の背景・濃い文字・濃紺の主要操作、端末がダーク表示のときは濃い灰色の背景・明るい文字・淡い黄色の主要操作へ自動で切り替わります。追加の設定ボタンはありません。状態は文字や枠の形でも示し、色だけで区別しません。

文字の対象色ペアは7:1以上、操作境界とフォーカス枠は3:1以上のコントラストを検査します。これだけで全アクセシビリティ適合を保証するものではなく、当事者による実機評価が必要です。

## 検証

```sh
node --test tests/*.test.js
node --check docs/app.js
```

保存・オフライン起動・バックグラウンド再生・実ファイルの重複判定は、このモックの実装範囲に含みません。

表示・操作の確認は公開したGitHub Pagesで行います。検証用のローカルサーバーは使用しません。
